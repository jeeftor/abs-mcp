# Audiobookshelf MCP Reference

This is the implemented MCP surface for `abs-mcp`. Outputs are JSON structured
content unless noted. Mutating tools are blocked when `ABS_READ_ONLY=true`, which
is the default.

Common ABS client failures include authentication or permission errors, missing
libraries or items, non-2xx Audiobookshelf HTTP responses, network failures, and
response decode errors.

## Tools

| Tool | Purpose | Key inputs | Output summary | Behavior | Common errors |
| --- | --- | --- | --- | --- | --- |
| `abs_health_check` | Validate authenticated ABS access. | None. | `ok`, configured `baseUrl`, `readOnly`, authenticated `username`/`userType`, visible `libraryCount`. | Read-only. | Current user or library list request fails. |
| `abs_list_libraries` | List libraries visible to the token. | None. | `libraries[]` with `id`, `name`, `mediaType`, `folders[]`; `count`. | Read-only. | Library list request fails. |
| `abs_get_library` | Get one library summary. | `libraryId` required. | `library` with `id`, `name`, `mediaType`, `folders[]`. | Read-only. | Missing `libraryId`; ABS cannot find or return the library. |
| `abs_list_library_items` | List one bounded page of library items. | `libraryId` required; optional `limit` default `25`, cap `100`; `offset` default `0`; `sort`; `desc`; `filter`; `include[]`; `minified`; `collapseSeries`. | `items[]` with item IDs, paths, missing/invalid flags, title/author/series, files, duration, size; `total`, `limit`, `offset`, `page`, `count`, requested sort/filter fields. | Read-only. | Missing `libraryId`; negative `limit` or `offset`; `offset` not a multiple of `limit`; ABS list request fails. |
| `abs_get_library_item` | Get one item summary. | `itemId` required. | `item` with ID, library ID, media type, path, missing/invalid flags, title/author/series, files, duration, size. | Read-only. | Missing `itemId`; ABS cannot find or return the item. |
| `abs_search_library` | Search one library. | `libraryId` and `query` required; optional `limit` default `12`, cap `50`. | `libraryId`, `query`, normalized `limit`, and raw ABS search `data`. | Read-only. | Missing `libraryId` or `query`; negative `limit`; ABS search request fails. |
| `abs_search_ebooks` | Search one library for items that have ebook files. | `libraryId` required; optional `query` matched against title, author, series, ISBN/ASIN, and ebook filename; optional `limit` default `25`, cap `100`. | Matching compact `items[]`, `checkedCount`, `ebookCount`, `matchedCount`, `returnedCount`, `truncated`. | Read-only. | Missing `libraryId`; negative `limit`; ABS item-list request fails. |
| `abs_preview_ebook_device_send` | Preview ebook device-send without sending to the device. | `libraryId` and `query` required; optional `deviceName`; optional `maxCandidates` default `10`, cap `50`. | Compact ebook `candidates[]`, sanitized ereader `devices[]`, `ready`, `confirmation` only when exactly one ebook and one saved device name resolve, and `nextTool` for the send step. No match, ambiguous matches, unknown device, or multiple unselected devices return `ready=false`. ABS still validates device access during send. | Read-only. Use before `abs_send_ebook_by_query` or `abs_send_ebook_to_device` so mutation happens only after preview. | Missing inputs; negative `maxCandidates`; ABS item-list or device-list request fails. |
| `abs_get_library_stats` | Read ABS stats for one library. | `libraryId` required. | `libraryId` and raw ABS stats `data`. | Read-only. | Missing `libraryId`; ABS stats request fails. |
| `abs_get_filter_data` | Read ABS filter data for one library. | `libraryId` required. | `libraryId` and raw ABS filter `data`. | Read-only. | Missing `libraryId`; ABS filterdata request fails. |
| `abs_list_library_authors` | List one bounded page of authors for a library. | `libraryId` required; optional `limit` default `25`, cap `100`; `offset` default `0`; `sort`; `desc`; `filter`; `include[]`; `minified`. | `libraryId`, normalized `limit`, `offset`, `page`, requested sort/filter/include fields, and raw ABS author-list `data`. | Read-only. | Missing `libraryId`; negative `limit` or `offset`; `offset` not a multiple of normalized `limit`; ABS author-list request fails. |
| `abs_get_author` | Get one author. | `id` required; optional `include[]`, such as `items` and `series`. | `id`, normalized `include[]`, and raw ABS author `data`. | Read-only. | Missing `id`; ABS author request fails. |
| `abs_list_library_series` | List one bounded page of series for a library. | `libraryId` required; optional `limit` default `25`, cap `100`; `offset` default `0`; `sort`; `desc`; `filter`; `include[]`; `minified`. | `libraryId`, normalized `limit`, `offset`, `page`, requested sort/filter/include fields, and raw ABS series-list `data`. | Read-only. | Missing `libraryId`; negative `limit` or `offset`; `offset` not a multiple of normalized `limit`; ABS series-list request fails. |
| `abs_get_series` | Get one series. | `id` required; optional `include[]`, such as `progress` and `rssfeed`. | `id`, normalized `include[]`, and raw ABS series `data`. | Read-only. | Missing `id`; ABS series request fails. |
| `abs_list_collections` | List collections visible to the authenticated user. | None. | Raw ABS collections `data`. | Read-only. | ABS collection-list request fails. |
| `abs_get_collection` | Get one collection. | `id` required; optional `include[]`. | `id`, normalized `include[]`, and raw ABS collection `data`. | Read-only. | Missing `id`; ABS collection request fails. |
| `abs_get_items_in_progress` | List in-progress items for the configured ABS user. | Optional `limit` default `25`, cap `100`. | Normalized `limit`, `user` scope object, and raw ABS current-user items-in-progress `data`. | Read-only; user-state scoped to the configured ABS token. | Negative `limit`; ABS items-in-progress request fails. |
| `abs_get_listening_stats` | Get listening statistics for the configured ABS user. | None. | `user` scope object and raw ABS current-user listening stats `data`. | Read-only; user-state scoped to the configured ABS token. | ABS listening-stats request fails. |
| `abs_list_listening_sessions` | List listening sessions for the configured ABS user. | Optional `limit` default `25`, cap `100`; optional `page` default `0`. | Normalized `limit`, `page`, `user` scope object, and raw ABS current-user listening sessions `data`. | Read-only; user-state scoped to the configured ABS token. | Negative `limit` or `page`; ABS listening-sessions request fails. |
| `abs_get_item_progress` | Get progress for one item for the configured ABS user. | `itemId` required; optional `episodeId` for podcast episodes. | `itemId`, optional `episodeId`, `user` scope object, and current-user ABS `progress` object. | Read-only; user-state scoped to the configured ABS token. | Missing `itemId`; ABS progress request fails or returns not found when that user has no progress for the item. |
| `abs_list_bookmarks` | List bookmarks for the configured ABS user. | Optional `itemId` to filter bookmarks by library item. | `bookmarks[]` with `libraryItemId`, `time`, `title`, `createdAt`; `count`; optional filter `itemId`. | Read-only; user-state scoped to the configured ABS token. | ABS current-user request fails. |
| `abs_update_item_progress` | Create or update progress for one item for the configured ABS user. | `itemId` required; optional `episodeId`; at least one of `duration`, `progress`, `currentTime`, `isFinished`, `hideFromContinueListening`, `ebookLocation`, or `ebookProgress` required. | `triggered`, `itemId`, and optional `episodeId`. | Mutates current-user progress through `PATCH /api/me/progress/:itemId/:episodeId?`; blocked by read-only mode; user-state scoped to the configured ABS token. | `ABS_READ_ONLY=true`; missing `itemId`; no progress fields; negative `duration` or `currentTime`; `progress` or `ebookProgress` outside 0..1; ABS progress update request fails. |
| `abs_create_bookmark` | Create a bookmark for the configured ABS user. | `itemId`, non-negative `time`, and nonblank `title` required. | `triggered`, `itemId`, and ABS `bookmark`. | Mutates current-user bookmarks through `POST /api/me/item/:id/bookmark`; blocked by read-only mode; user-state scoped to the configured ABS token. | `ABS_READ_ONLY=true`; missing `itemId`; negative `time`; blank `title`; ABS bookmark creation request fails. |
| `abs_update_bookmark` | Update a bookmark for the configured ABS user. | `itemId`, non-negative `time`, and nonblank `title` required. | `triggered`, `itemId`, and ABS `bookmark`. | Mutates current-user bookmarks through `PATCH /api/me/item/:id/bookmark`; blocked by read-only mode; user-state scoped to the configured ABS token. | `ABS_READ_ONLY=true`; missing `itemId`; negative `time`; blank `title`; ABS bookmark update request fails or returns not found. |
| `abs_list_backups` | List server backup records visible to the configured ABS token. | None. | `backups[]` with source-backed ABS backup fields; `count`. | Read-only; requires sufficient ABS backup permissions. | ABS backup-list request fails. |
| `abs_create_backup` | Create one server backup. | None. | `triggered` and ABS `backup`. | Mutates ABS server backup state through `POST /api/backups`; blocked by read-only mode; requires sufficient ABS backup permissions. | `ABS_READ_ONLY=true`; ABS backup creation request fails. |
| `abs_list_ereader_devices` | List saved ereader device names from ABS email settings. | None. | `devices[]` with `name`, optional availability metadata, and redacted empty `email`; `count`. | Read-only; uses admin-scoped `GET /api/emails/settings` but does not return SMTP settings or saved device email addresses. | ABS token lacks permission for email settings; ABS email-settings request fails. |
| `abs_send_ebook_to_device` | Send one ebook library item to a saved ereader device. | `itemId` and exact `deviceName` required. | `triggered`, `itemId`, `deviceName`, and raw ABS response `data` when returned. | Mutates through ABS `POST /api/emails/send-ebook-to-device`; blocked by read-only mode; scoped by ABS to devices and library items accessible to the configured user. | `ABS_READ_ONLY=true`; missing `itemId`; missing `deviceName`; ABS cannot find the device, item, or ebook file; ABS device delivery fails. |
| `abs_send_ebook_by_query` | Resolve exactly one ebook search match, then send it to a saved ereader device. | `libraryId`, `query`, `deviceName`, and exact `confirmation` required; optional `maxCandidates` default `10`, cap `50`. Confirmation must equal `send ebook <resolvedItemId> to <deviceName>`. | `triggered`, `libraryId`, `query`, `deviceName`, resolved compact `item`, and raw ABS response `data` when returned. | Mutates through ABS `POST /api/emails/send-ebook-to-device`; blocked by read-only mode; requires a single ebook match and exact confirmation. | `ABS_READ_ONLY=true`; missing inputs; no ebook match; ambiguous ebook matches; wrong confirmation; ABS device delivery fails. |
| `abs_get_item_metadata_object` | Read the raw metadata object for one item. | `itemId` required. | `itemId` and raw ABS metadata-object `data`. | Read-only. | Missing `itemId`; ABS metadata-object request fails, including permission failures. |
| `abs_find_misorganized_items` | Audit item folders against author/title or author/series/title layout conventions. | `libraryId` required; optional `convention` of `auto`, `author-title`, or `author-series-title`; optional `limit` default `50`, cap `200`; optional `includeOrganized`. | Counts for checked, organized, misorganized, and unclassifiable items; returned item findings with current/expected relative paths, reasons, confidence, and missing/invalid flags. | Read-only. | Missing `libraryId`; unsupported convention; negative `limit`; ABS library or item-list request fails. |
| `abs_scan_library` | Trigger a library scan. | `libraryId` required; `force` boolean. | `triggered`, `libraryId`, `force`. | Mutates ABS scan state; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `libraryId`; ABS scan request fails. |
| `abs_scan_library_and_wait` | Trigger a library scan, then poll item count. | `libraryId` required; `force`; optional `expectedTotal`; `timeoutSeconds` default `30`, cap `300`; `pollIntervalMilliseconds` default `1000`, cap `60000`. | `triggered`, `completed`, `timedOut`, `observedTotal`, `attempts`, timeout/poll settings, elapsed milliseconds. Timeout is returned as status, not an error. | Mutates ABS scan state; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `libraryId`; negative `expectedTotal`, timeout, or poll interval; scan or observation request fails. |
| `abs_scan_item` | Rescan one directory-backed item. | `itemId` required. | `triggered`, `itemId`, optional ABS `result`. | Mutates ABS scan state; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `itemId`; ABS item scan request fails. |
| `abs_update_item_metadata` | Update selected item metadata fields. | `itemId` required; at least one typed field required. Optional fields: `title`, `subtitle`, `author`, `description`, `publishedYear`, `publishedDate`, `publisher`, `isbn`, `asin`, `language`, `releaseDate`, `explicit`, `abridged`, `narrators[]`, `genres[]`, `tags[]`, `authors[]`, `series[]` with `name` and optional `sequence`. | `triggered`, `itemId`, and raw ABS response `data` when returned. | Mutates ABS metadata through `PATCH /api/items/:id/media`; blocked by read-only mode. Only source-verified catalog fields are exposed; cover URL/upload, audio files, chapters, tracks, ebook files, feed URLs, and podcast auto-download settings are not accepted by this tool. | `ABS_READ_ONLY=true`; missing `itemId`; no metadata fields; blank title, author, array value, or series name; ABS metadata update request fails. |
| `abs_update_item_cover` | Update one item cover path. | `itemId` and `cover` required. | `triggered`, `itemId`, and raw ABS response `data` when returned. | Mutates ABS cover through `PATCH /api/items/:id/cover` with `{cover:<path>}`; blocked by read-only mode. Cover upload is not implemented. | `ABS_READ_ONLY=true`; missing `itemId`; missing `cover`; ABS cover update request fails. |
| `abs_remove_item_cover` | Remove one item cover. | `itemId` required; `confirmation` must exactly equal `remove cover from <itemId>`. | `triggered`, `itemId`. | Destructive mutation through `DELETE /api/items/:id/cover`; blocked by read-only mode and requires exact confirmation. | `ABS_READ_ONLY=true`; missing `itemId`; wrong confirmation; ABS cover removal request fails. |
| `abs_match_item` | Planned item metadata match. | `itemId` required; optional `provider`; `payload` reserved until restricted source-verified input is available. | Not implemented yet. | Planned mutation; advertised for discovery; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `itemId`; not implemented until safe match semantics are verified. |
| `abs_update_item_chapters` | Replace one item chapter list. | `itemId` required; `chapters[]` required with `title`, `start`, `end`; `expectedChapterCount` must exactly equal the number of provided chapters. | `triggered`, `itemId`, and raw ABS response `data` when returned. | Mutates ABS chapters through `POST /api/items/:id/chapters`; blocked by read-only mode and guarded by expected chapter count. | `ABS_READ_ONLY=true`; missing `itemId`; empty chapters; count mismatch; invalid chapter title or times; ABS chapter update request fails. |
| `abs_update_item_tracks` | Planned item track update. | `itemId` required; `payload` reserved until source verification. | Not implemented yet. | Planned mutation; advertised for discovery; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `itemId`; not implemented until ABS source and fixture behavior are verified. |
| `abs_create_collection` | Create a collection with an initial item list. | `libraryId`, `name`, and non-empty `itemIds[]` required; optional `description`. | `triggered`, optional response `id`, and raw ABS response `data` when returned. | Mutates ABS collections through `POST /api/collections`; blocked by read-only mode. ABS requires at least one book item. | `ABS_READ_ONLY=true`; missing `libraryId`, `name`, or `itemIds`; blank item ID; ABS collection creation request fails. |
| `abs_update_collection` | Update one collection name or description. | `collectionId` required; at least one of `name` or `description` required. | `triggered`, collection `id`, and raw ABS response `data` when returned. | Mutates ABS collections through `PATCH /api/collections/:id`; blocked by read-only mode. Item reordering is not implemented. | `ABS_READ_ONLY=true`; missing `collectionId`; missing both `name` and `description`; ABS collection update request fails. |
| `abs_delete_collection` | Delete one collection after confirmation. | `collectionId` required; `confirmation` must exactly equal `delete collection <collectionId>`. | `triggered`, collection `id`, and raw ABS response `data` when returned. | Destructive mutation through `DELETE /api/collections/:id`; blocked by read-only mode and requires confirmation. | `ABS_READ_ONLY=true`; missing `collectionId`; wrong confirmation; ABS collection deletion request fails. |
| `abs_add_collection_item` | Add one item to a collection. | `collectionId` and `itemId` required. | `triggered`, collection `id`, and raw ABS response `data` when returned. | Mutates ABS collections through `POST /api/collections/:id/book`; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `collectionId` or `itemId`; ABS collection item add request fails. |
| `abs_remove_collection_item` | Remove one item from a collection after confirmation. | `collectionId` and `itemId` required; `confirmation` must exactly equal `remove item <itemId> from collection <collectionId>`. | `triggered`, collection `id`, and raw ABS response `data` when returned. | Destructive mutation through `DELETE /api/collections/:id/book/:bookId`; blocked by read-only mode and requires confirmation. | `ABS_READ_ONLY=true`; missing `collectionId` or `itemId`; wrong confirmation; ABS collection item removal request fails. |
| `abs_create_playlist` | Create a playlist. | `libraryId` and `name` required; optional `description`; optional `items[]` with required `itemId` and optional `episodeId`. | `triggered`, optional response `id`, and raw ABS response `data` when returned. | Mutates ABS playlists through `POST /api/playlists`; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `libraryId` or `name`; blank playlist item ID; ABS playlist creation request fails. |
| `abs_update_playlist` | Update one playlist name or description. | `playlistId` required; at least one of `name` or `description` required. | `triggered`, playlist `id`, and raw ABS response `data` when returned. | Mutates ABS playlists through `PATCH /api/playlists/:id`; blocked by read-only mode. Item reordering is not implemented. | `ABS_READ_ONLY=true`; missing `playlistId`; missing both `name` and `description`; ABS playlist update request fails. |
| `abs_delete_playlist` | Delete one playlist after confirmation. | `playlistId` required; `confirmation` must exactly equal `delete playlist <playlistId>`. | `triggered`, playlist `id`, and raw ABS response `data` when returned. | Destructive mutation through `DELETE /api/playlists/:id`; blocked by read-only mode and requires confirmation. | `ABS_READ_ONLY=true`; missing `playlistId`; wrong confirmation; ABS playlist deletion request fails. |
| `abs_add_playlist_item` | Add one item or podcast episode to a playlist. | `playlistId` and `itemId` required; optional `episodeId`. | `triggered`, playlist `id`, and raw ABS response `data` when returned. | Mutates ABS playlists through `POST /api/playlists/:id/item`; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `playlistId` or `itemId`; ABS playlist item add request fails. |
| `abs_remove_playlist_item` | Remove one item or episode from a playlist after confirmation. | `playlistId` and `itemId` required; optional `episodeId`; `confirmation` must exactly equal `remove item <itemId> from playlist <playlistId>`. | `triggered`, playlist `id`, and raw ABS response `data` when returned. | Destructive mutation through `DELETE /api/playlists/:id/item/:libraryItemId/:episodeId?`; blocked by read-only mode and requires confirmation. The episode path segment is omitted when `episodeId` is blank. | `ABS_READ_ONLY=true`; missing `playlistId` or `itemId`; wrong confirmation; ABS playlist item removal request fails. |
| `abs_remove_library_items_with_issues` | Remove missing or invalid items from one library after confirmation. | `libraryId` required; `confirmation` must exactly equal `remove issues from <libraryId>`; optional `expectedIssueCount`. | `triggered`, `libraryId`, issue count before cleanup, removed count, remaining issue count, up to 100 issue item IDs observed before cleanup. If no issues exist, `triggered=false`. | Mutates ABS library rows; blocked by read-only mode. | `ABS_READ_ONLY=true`; missing `libraryId`; wrong confirmation; negative or mismatched `expectedIssueCount`; list/delete/re-list request fails. |

## Resources

All resources return `application/json`.

| Resource | Purpose | Output summary | Errors |
| --- | --- | --- | --- |
| `abs://server/info` | Health summary. | Same shape as `abs_health_check`. | Wrong URI; health requests fail. |
| `abs://libraries` | Visible libraries. | Same shape as `abs_list_libraries`. | Wrong URI; library list request fails. |
| `abs://api-inventory/current` | Generated source-backed ABS API route inventory. | Inventory JSON, or `{ "available": false, "error": ... }` if loading failed. | Wrong URI; JSON marshaling failure. |
| `abs://fixture/status` | Local Docker fixture status without secrets. | Fixture directory/config presence, fixture URLs and SQLite paths from `.env.testing`, token configured flag and token length, expected item counts. | Wrong URI. |
| `abs://libraries/{library_id}` | One library by ID. | Same shape as `abs_get_library`. | Invalid URI; missing/not found library; ABS request fails. |
| `abs://libraries/{library_id}/items{?limit,offset}` | One bounded item page. | Same shape as `abs_list_library_items` for `libraryId`, `limit`, and `offset`. | Invalid URI; non-integer `limit`/`offset`; item-list validation or ABS request fails. |
| `abs://libraries/{library_id}/stats` | Raw library stats. | Same shape as `abs_get_library_stats`. | Invalid URI; ABS stats request fails. |
| `abs://libraries/{library_id}/filterdata` | Raw library filter data. | Same shape as `abs_get_filter_data`. | Invalid URI; ABS filterdata request fails. |
| `abs://items/{item_id}` | One item by ID. | Same shape as `abs_get_library_item`. | Invalid URI; missing/not found item; ABS request fails. |
| `abs://items/{item_id}/metadata-object` | Raw item metadata object. | Same shape as `abs_get_item_metadata_object`. | Invalid URI; ABS metadata-object request fails. |

## Prompts

| Prompt | Arguments | Purpose |
| --- | --- | --- |
| `abs_library_audit` | Optional `libraryId`. | Guides a read-only audit using health, library, item-list, and item-read calls; warns not to mutate unless explicitly requested and read-only mode is disabled. |
| `abs_scan_troubleshooting` | Optional `libraryId`. | Guides scan diagnosis, including before/after item reads, safe scan use, and confirmed cleanup only when requested. |
| `abs_api_update_review` | None. | Guides source inventory diff review, MCP schema/client/test updates, and verification against source and fixture behavior. |
